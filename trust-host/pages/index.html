GBO-demo trust-host

Dit is een demonstratieomgeving. De lijsten en certificaten op deze host zijn testmateriaal: ze zijn niet bij de EU aangemeld en hebben geen rechtsgevolg.

This is a demonstration environment. The lists and certificates on this host are test material: they are not notified to the EU and have no legal effect.

Lists of Trusted Entities (LoTE)

  • PIDProviders.jwt: PID-aanbieders / PID providers
  • PubEAAProviders.jwt: PuB-EAA-aanbieders / PuB-EAA providers
  • WRPACProviders.jwt: uitgevers van toegangscertificaten / access certificate providers
  • WRPRCProviders.jwt: uitgevers van registratiecertificaten / registration certificate providers

Root van de lijsten / List signing root

  • lote-ca-cert.pem: controleer de SHA-256-fingerprint tegen de README van de trust-host voordat u de root vertrouwt.

Check the root's SHA-256 fingerprint against the trust host README before you trust it.

Status en intrekking / Status and revocation

  • reader-root.crl: ingetrokken toegangscertificaten / revoked access certificates
  • wrprc/1: statuslijst van registratiecertificaten / registration certificate status list
